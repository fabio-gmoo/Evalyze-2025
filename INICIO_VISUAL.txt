PASO 1️⃣ : INSTALAR OLLAMA
────────────────────────────────────────────────────────────────────────────
  1. Descargar: https://ollama.ai/
  2. Instalar en tu computadora
  3. Ejecutar: ollama serve
  4. En otra terminal: ollama pull llama3.2
  
  ✅ Señal de éxito: Ver "Listening on 127.0.0.1:11434"


PASO 2️⃣ : INICIAR 4 SERVICIOS (En 4 terminales diferentes)
────────────────────────────────────────────────────────────────────────────

  TERMINAL 1 - OLLAMA (PRIMERO)
  ─────────────────────────────────
  $ ollama serve
  
  Esperado: "Listening on 127.0.0.1:11434"
  

  TERMINAL 2 - AI SERVICE (Espera 5 seg después de Ollama)
  ────────────────────────────────────────────────────────
  $ cd Evalyze-2025\ai-service
  $ python main.py
  
  Esperado: "Uvicorn running on http://0.0.0.0:8001"
  

  TERMINAL 3 - DJANGO BACKEND (Espera 3 seg después de AI Service)
  ──────────────────────────────────────────────────────────────────
  $ cd Evalyze-2025\django-docker
  $ python manage.py migrate    (primera vez solo)
  $ python manage.py runserver
  
  Esperado: "Starting development server at http://127.0.0.1:8000/"
  

  TERMINAL 4 - ANGULAR FRONTEND (Espera 3 seg después de Django)
  ───────────────────────────────────────────────────────────────
  $ cd Evalyze-2025\Eva-Front
  $ npm start
  
  Esperado: "Application bundle generation complete"

❌ "ModuleNotFoundError"
   ↳ Ejecutar: pip install -r requirements.txt

❌ "Port already in use"
   ↳ Ejecutar con puerto diferente: python manage.py runserver 0.0.0.0:8001

❌ "Cannot connect to Ollama"
   ↳ Verificar que ollama serve está corriendo en Terminal 1

❌ "Cannot connect to AI Service"
   ↳ Verificar que está corriendo en Terminal 2

❌ "Django database locked"
   ↳ Ejecutar: python manage.py migrate

❌ "Frontend no carga"
   ↳ Limpiar cache: Ctrl+Shift+Delete
   ↳ Recargar: Ctrl+F5
